## Overview

A personal industrial-design project exploring geometry, fit, and materials for an everyday-carry object. The whole thing is modeled in Fusion 360 and produced on a desktop FDM printer.

More detail (and photos of the final piece) coming soon.

## The interactive model

The viewer above is a live 3D model rendered with Three.js. Drag to rotate, scroll to zoom. The file is a binary STL exported straight from Fusion 360 (File → 3D Print → STL, no conversion step needed).
